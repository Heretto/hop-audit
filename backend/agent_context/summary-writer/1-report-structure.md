# Full findings report

The full report lists every firm finding with exact quotes, plus the items for review. It is the document the prospect gets in the walkthrough, so it is factual and plain: no adjectives about the prospect, no sales copy.

## Sections, in order

Each section opens with a one-sentence lead that states the count and the point.

1. **Summary**: the headline count, the number of articles and help centers, the number High and what High means. The counting rule in two sentences (what was counted, what was excluded), and how many items are listed for review. A table: Help center | Site | Articles reviewed (include any locale not reviewed, with the reason). One line: quotes are exact, trimmed to the clause that matters; articles are identified by URL slug.
2. **Findings by category**: table Category | Total | High | Medium | Low, sorted by total, with a bold Total row. Under it, the one-line severity definitions.
3. **Contradictions between articles (n)**: table ID | Severity | Help center | Issue | Conflicting text (article). High first, then Medium, then Low.
4. **[Language] and [language] versions don't match (n)**: table ID | Severity | Issue | [Primary language] | [Other language] (and article). Mention if two versions of one language disagree with each other.
5. **Instructions that don't match each other or the app (n)**: table ID | Severity | Help center | Issue | Text (article).
6. **Remaining categories**: one `###` subsection per category with findings (links and duplicates, retired products, outdated content, terminology, structure and publishing errors, scope errors, disclosure text), each with a table ID | Severity | Help center | Issue | Detail. The section lead names any High items in it.
7. **Items for review (n)**: table ID | Help center | Issue | Text (article) | Why it may be accurate. Lead: these may be accurate depending on internal policy, so they are not counted.

Omit any category with zero firm findings. Keep the audit's IDs so the report, the one-sheet, and the conversation refer to the same items.

## Writing rules

- Quote exactly; never paraphrase inside quotation marks. Translate non-English quotes in parentheses after the quote.
- Name the article slug for every quote.
- Short leads, plain words, no marketing language. The findings speak for themselves.
- Don't mention Heretto's product in the report body; the walkthrough does that.
- Don't include internal notes such as "verify before sending".
