# Counting rule and severity

The findings go to a documentation head. One finding that turns out to be wrong or petty undoes the whole piece, so log only what meets the counting rule.

## The counting rule

Count content that is **wrong, conflicting, outdated, or missing its scope**. Do not count differences where both versions are accurate. Different wording, different but true regional policies, or repeated identical passages are not issues: identical repetition can be a sign the prospect already single-sources content, so it proves nothing.

## Severity

- **High**: a customer could act on wrong information (money, eligibility, contact details, account actions), or the content is compliance-sensitive.
- **Medium**: confusing, conflicting, or outdated, with lower stakes.
- **Low**: cosmetic or structural.

Downgrade a finding's severity when you move it into "inconsistent messaging" territory (e.g., the escheatment example went High → Medium).
